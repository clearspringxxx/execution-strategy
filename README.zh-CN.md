# Claude Code 执行策略

解决 Claude Code 「直接执行，不先给方案」的问题。

## 问题

Claude Code 默认行为是收到任务后直接改代码、跑命令，而不是先展示方案等用户确认。方向错了浪费 token，产出不符合预期。

## 解决方案

六类任务分类 + 三层判定逻辑 + 行为约束 + 执行率优化。

| 类型 | 判定 | 行为 |
|------|------|------|
| ① 知识型 | 问原理/原因/用法 | 直接回答，不动主机 |
| ② 实操型 | 帮我改/帮我加 | 先方案，后执行 |
| ③ 任务型 | 设计/重构/架构 | 方案+利弊，用户选择 |
| ④ 修复型 | 报错/环境/故障 | 直接干，边做边说 |
| ⑤ 聊天型 | 日常闲聊/问候/非技术话题 | 正常聊天，不走任务流程 |
| ⑥ 其他型 | 拿不准 | 给选项，用户选 |

判定逻辑：显式意图词 → 关键词匹配 → 上下文推断，详见 `execution.md`。

### 执行率优化

针对"长对话后策略失效"的问题，采用以下优化：

- **核心规则前置**：文件最开头用引用格式突出核心要求
- **简化输出格式**：`[①]` 代替冗长的分类行，降低执行成本
- **强烈措辞**：用"禁止"、"必须"、"违反则回答无效"强化约束
- **重复强调**：开头、中间、结尾三次重申核心规则
- **自检机制**：每次回答前默念类型判断，附带自检清单
- **后果强化**：明确"违反规则 = 回答无效"

## 快速导入

### Windows

双击 `import.bat`，或终端执行：

```powershell
.\import.ps1
```

### Linux / macOS

```bash
chmod +x ./import.sh && ./import.sh
```

导入完成，新会话自动生效。

## 工作原理

规则文件复制到 `~/.claude/strategies/` 目录，通过 CLAUDE.md 的 `@` 语法引用，避免 CLAUDE.md 文件过大。
