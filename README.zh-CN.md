# Claude Code 执行策略

解决 Claude Code 「直接执行，不先给方案」的问题。

## 问题

Claude Code 默认行为是收到任务后直接改代码、跑命令，而不是先展示方案等用户确认。方向错了浪费 token，产出不符合预期。

## 解决方案

文件开头先声明定位：本策略是权限模式之前的「行为屏障」，只决定做法与回答方式，工具与文件的审批交给当前模式（询问/计划/编辑/自动/跳过），两层叠加、互不冲突。随后是四条核心规则，全部内容约 35 行：

1. **先方案后执行** — 改文件、跑命令、动配置的任务，先给方案（小改动一句话，大改动分点列变更、利弊、风险），等确认再动手。
2. **问答不动手** — 问原理、问原因、问用法，直接回答，不碰主机。
3. **修复默认直接干** — 报错、环境、故障直接修，边做边报告；但删除、覆盖、重构、换依赖先说明再动手。
4. **用户指令优先** — 用户说"直接做"、"别走流程"、"赶时间"，策略层规则全部让位；模式层审批闸门不受影响，由用户自行切换。

边界条款覆盖新增功能、设计任务、意图不明、中途叫停、范围蔓延等场景。全篇靠一句自检收束：*用户同意了吗？没有就先给方案。*

## 设计说明

- 不输出分类标记，不搞多层判定表。规则短到能在长对话中保持有效。
- 与权限模式分层：策略管「怎么做」，模式管工具审批；模式松（自动/跳过）不削弱策略，模式严（询问/编辑/计划）只是多一道闸门，两者不冲突。
- 有显式 override 条款，策略永远不会和用户自己的指令打架（override 只作用于策略层，模式闸门需用户自行切换）。
- 规则文件通过 CLAUDE.md 的 `@` 语法引用，避免 CLAUDE.md 文件过大。

## 快速导入

### Windows

双击 `import.bat`，或终端执行：

```powershell
.\import.ps1
```

### Linux / macOS

```bash
chmod +x ./import.sh && ./import.sh
```

导入完成，新会话自动生效。

## 工作原理

规则文件复制到 `~/.claude/strategies/` 目录，通过 CLAUDE.md 的 `@` 语法引用，避免 CLAUDE.md 文件过大。
